# oc1703wc_deepauto
R notebooks used for data analysis in Salcedo et al., in prep. assessing distribution and diversity of inorganic carbon fixating microrganisms in the deep sea

OC17_contig_tax_abundance_public.rmd - uses curated_scaffold_taxonomy_2500bp_v2.csv (generated by alex jaffe) to generate supp figure 1
OC17_genewise_analysis_public.rmd - used to generate figure 1. goes from assembly --> coverage based gene abundance. uses bitscore_thresholds.csv and CAT_gene_lengths.csv
OC17_geochemistry_cor_public.rmd - uses nutrients_ODV published in N Arandia-Gorostidi et al., 2023 (ISME) to determine correlations between coverage based gene abundance and geochemistry
OC17_refinedMAG_annotation_public.rmd - annotation pipeline for manually refined MAGs (done in anvio) containing genes for inorganic carbon fixation
OC17_refinedMAG_cat_abundance_fig3_public.rmd - uses DRAM_v5 and coverM abundance values for refined genomes to generate figure 3. 
OC17_refinedMAG_cat_potential_fig4_public.rmd - uses DRAM_v5 and refined annotated genomes to generate figure 4.
OC17_refinedMAG_tax_abundance_fig2B_public.Rmd - uses GTDB-tk assigned taxonomy and coverM abundance values of refined genomes to generate panel B in figure 2
refined_auto_MAGs_edited.csv - master metadata spreadsheet generated displaying gene presence in refined genomes. also includes phylogenetic classification and genome completeness/contamination
